# Известные ограничения и внешняя настройка

1. **OpenAI не настроен.** В окружении отсутствовал ключ; реальная генерация, доступ к моделям, внешняя сеть и биллинг не проверялись. Реальный SDK реализован, тесты используют только тестовые провайдеры и mock HTTP.
2. **SMTP не настроен.** Серверная логика сброса пароля готова, фактическая доставка писем не проверена. Подтверждения email при регистрации и двухфакторного входа нет.
3. **Физический Android не тестировался.** Проверены адаптивные размеры в Chromium; системную клавиатуру, сохранение файлов и производительность необходимо проверить на устройстве. Учтены safe-area, dvh, уменьшение движения, крупные элементы ввода.
4. **Форматы 9:16 и 16:9 не обещаны для любой модели.** Default GPT Image-конфигурация предлагает 1:1, 2:3, 3:2. Неподдерживаемый точный формат явно обозначается.
5. **SQLite — один процесс.** PostgreSQL/S3 имеют описанные границы адаптации, но адаптеры не реализованы и не тестировались.
6. **Нет фоновой распределённой очереди.** Image job живёт внутри процесса HTTP-сервера. При перезапуске отмечается interrupted; клиент может повторить запрос. Провайдер может списать стоимость до локальной отмены.
7. **Расходы ограничены запросами, не рублями/долларами.** Дневные квоты включают ошибки и отмены после резервирования. Они обнуляются в 00:00 UTC. Денежный лимит проекта задаётся у провайдера.
8. **История ограничена.** До 1000 диалогов пользователя, максимум 500 сообщений в одном. Список показывает до 200 последних совпадений поиску; поиск выполняется на сервере. Контекст API: последние 40 сообщений в пределах MAX_CONTEXT_CHARS, не точный токенизатор. Полная история остаётся в БД.
9. **Админ-списки** показывают до 500 последних пользователей и приглашений. Изменение роли/удаление администратора требует серверного обслуживания, чтобы не потерять управление.
10. **Галерея** выдаёт по 50 записей с догрузкой. Генерация — одно PNG за запрос. Нет редактирования, image-to-image, вложений в текстовый чат, общих ссылок или публичных галерей.
11. **Хранилище локальное.** Нет автоматических резервных копий, encryption-at-rest, мониторинга свободного места или очистки всех аварийных orphan-файлов. Есть очередь штатного удаления файлов.
12. **Публикация не выполнялась.** HTTPS, reverse proxy и Docker инструкции требуют проверки в выбранном хостинге перед запуском. Автозапуск после ограничений доступа самой сессии разработки не настроен.

Не включены сознательно по ТЗ: Cloudflare-интеграция, изменение существующих Workers/DNS, платежи, СБП, баланс, подписки и публичная публикация.
