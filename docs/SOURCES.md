# Документация интеграций

Первичные источники, сверенные при реализации:

- OpenAI Node SDK: https://github.com/openai/openai-node
- Chat streaming: https://github.com/openai/openai-node/blob/main/docs/helpers.md
- Chat Completions API: https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create
- Images API и форматы: https://developers.openai.com/api/docs/guides/image-generation
- Fastify server: https://fastify.dev/docs/latest/Reference/Server/

Типы установленных SDK и lockfile — основа воспроизводимости конкретной сборки. Доступность моделей и параметры провайдера могут меняться; живые запросы в этой работе не выполнялись.
