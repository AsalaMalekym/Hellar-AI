# Отчёт о проверке Hellar AI Cosmic Edition

Дата: 9 ноября 2026, Москва. Среда: Node.js 24.22.1, Linux, Chromium облачного браузера. Статус: локальная бета для установки, без публикации.

## Автоматические проверки

`npm test`: **22 теста, 22 прошли**. Каждый сценарий использует изолированную временную SQLite-БД и удаляет тестовые данные. Реальные API-ключи и реальная почта не используются.

| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Регистрация без действительного приглашения | Отклонена API, включая истёкший и отозванный код                                                               |
| Повторное использование приглашения         | Отклонено; два параллельных запроса создают ровно одного пользователя                                          |

Дополнительно команда `admin:create` проверена в отдельной временной БД через интерактивный терминал. Ввод пароля не отображался; создан ровно один администратор. Аккаунты владельца и действующие сервисы не использовались.

## Проверка интерфейса

В браузере проверены главная, вход, регистрация, чат, студия изображений, кабинет и админ-панель при viewport 360, 390, 412, 430 px. Для каждой страницы измерены clientWidth и scrollWidth; переполнения по горизонтали нет. Полные измерения: `ui-metrics.json`. В Chromium с обычным scrollbar внутренний clientWidth иногда на 15 px меньше viewport; это учтено.

Проверены открытие/закрытие истории, выбор диалога, Markdown и код, форма профиля с длинным именем, сообщение о неподдерживаемом 9:16 и переход на 2:3. Основная главная снята с реального локального приложения. Приватные страницы визуально проверялись на **изолированных UI-фикстурах** без сетевых вызовов и без обхода авторизации. Фикстуры помечены на экране, не входят в production bundle. Авторизация и приватные API проверены интеграционными тестами настоящего backend.

Скриншоты находятся в `screenshots/`. Имена с `qa` обозначают визуальные тестовые данные, а не работающий ответ ИИ.

## Производительность и зависимости

- Первоначальный JS — около 286 КБ, около 92 КБ gzip; CSS — около 40 КБ / 10 КБ gzip. Чат, кабинет, студия и администрирование загружаются отдельно.
- Космос нарисован CSS, без тяжёлого видеофона и внешних шрифтов. Изображения галереи загружаются лениво.
- Уменьшение движения по prefers-reduced-motion и настройке профиля. На мобильном меньше эффектов; viewport использует dvh и interactive-widget=resizes-content.
- `npm audit`: 0 известных уязвимостей после обновления зависимостей. Машинный результат — `dependency-audit.json`. Это результат на дату проверки, не гарантия на будущее.

## Чистая установка

Архив установлен в отдельном каталоге: npm ci, сборка, 22 теста и smoke скомпилированного production-сервера прошли. Подробности: `CLEAN-INSTALL.md`.

## Не проверено живьём

- Реальные текстовые/image-запросы OpenAI, доступность моделей, квота, оплата API, внешний сетевой путь: ключ отсутствует.
- Настоящая доставка SMTP и переход по письму из почтового клиента.
- Физический Android, экранная клавиатура Black Shark, производительность на слабом телефоне и поведение системного браузера. Выполнена проверка мобильной геометрии в Chromium, а не тест на устройстве.
- Реальное HTTPS-развёртывание, reverse proxy, Docker runtime, PostgreSQL и S3. Это инструкции/точки расширения, не развёрнутые интеграции.
- Нагрузочное тестирование и независимый penetration test.

Эти ограничения требуют внешней настройки или устройства и не подменены демонстрационными «успешными» результатами.
