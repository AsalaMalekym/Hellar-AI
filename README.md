# Hellar AI — Cosmic Edition

Космический интерфейс, чат с ИИ, генерация изображений, личный кабинет и регистрация по приглашениям. Основа — сохранённая версия `hellar-cosmic-stage-8`; версия 0.9 добавляет адаптер Cloudflare и GitHub Actions.

**[Инструкция запуска в Cloudflare](docs/CLOUDFLARE.md)**

GitHub проверяет код при каждом push. Публикация запускается вручную через **Actions → Deploy Hellar to Cloudflare → Run workflow** после добавления секретов и адреса сайта. Сайт не опубликован самим фактом наличия этого репозитория.

## Устройство

- React/Vite — интерфейс.
- Workers Static Assets — размещение интерфейса.
- Worker + SQLite Durable Object — API, транзакции, аккаунты, история, общие квоты.
- R2 — закрытое хранилище картинок.
- OpenAI API — подключается серверным секретом. Ключ никогда не попадает в браузер.

Первоначальный владелец создаётся на `/setup` по отдельному секрету. Обычные пользователи регистрируются по приглашениям с обязательным подтверждением почты. Пароль задаётся по одноразовой ссылке из письма. Turnstile защищает открытие сайта, регистрацию и запрос восстановления. [Подключение почты и капчи](docs/EMAIL-CAPTCHA.md). Вход через ChatGPT не требуется.

## Проверка

```bash
npm ci
npm test
npm run build:cloudflare
npm run test:cloudflare
npx wrangler deploy --dry-run
```

Проверки Cloudflare запускают настоящий локальный runtime Workers: создание владельца, вход, CSRF, приглашения, роли, изоляция истории, SSE, R2 и сохранность после перезапуска. Внешний API имитируется; реальных платных запросов тесты не делают.

## Ограничения

В адаптере Cloudflare пока отключены загрузка аватаров и доставка писем сброса пароля. Смена известного пароля работает. Google OAuth, платежи и автоматический импорт старой базы не входят в эту версию. Доступность моделей и реальная генерация проверяются после настройки ключа.

Для запуска исходного Node-сервера: [README.node.md](README.node.md). Он использует локальный SQLite и файловое хранилище, а не Cloudflare bindings.
